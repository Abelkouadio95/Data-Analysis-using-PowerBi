# 📊 Power BI Sales Dashboard Adidas

Un dashboard interactif et dynamique développé sous **Power BI** permettant d’analyser les ventes selon plusieurs dimensions (produits, régions, méthodes de vente, périodes, etc.).  
Ce projet met l’accent sur la **visualisation claire**, la **navigation intuitive** et la **mise en avant des indicateurs clés**.

---

## 🚀 Fonctionnalités principales

### 🖥 Barre latérale (ouverte/fermée)
- **Filtres dynamiques** pour affiner les analyses :
  - Date
  - Région
  - Produits
- **Mode rétractable** (Open/Close) pour optimiser l’espace d’affichage.

---

### 📈 Visualisations interactives
- **Total des ventes par produit** *(diagramme en barres)*
- **Total des ventes par state** *(graphique en secteurs)*
- **Ventes par méthode de vente** 
- **Évolution des ventes dans le temps** *(courbe)*

---

### 📊 KPIs stratégiques
- **💰 Total Ventes** avec variation **par rapport au mois précédent** (+/- %)
- **📦 Unités vendues**
- **📅 Ventes de l'année précédente**
---

## 🛠 Technologies utilisées
- **Power BI Desktop** pour la conception du dashboard
- **DAX** pour les calculs et mesures personnalisées
- **Visualisations natives** et **visuels personnalisés** de Power BI Marketplace

## 📥 Installation
1. Télécharger le fichier `.pbix` depuis ce dépôt
2. Ouvrir le fichier dans **Power BI Desktop**
3. Connecter votre source de données (si nécessaire)
4. Profiter du dashboard interactif 🎯
